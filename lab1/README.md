## Демон для копирования файлов (Вариант 16)

### Требования
- C++17, Linux
- Права на запись в `/var/run` для pid-файла (или измените путь в `src/Daemon.cpp`)

### Сборка
```bash
bash build.sh build
```
Готовый бинарь: `bin/daemonizer`.

### Формат конфигурации
Файл конфигурации содержит:
- опционально: `interval=<milliseconds>` — период между итерациями
- правила копирования по строкам: `folder1 folder2 ext`

Пример:
```
# интервал 2 секунды
interval=2000

# копировать *.txt из ./in в ./out
./in ./out txt

# можно несколько правил
./a ./b log
```

Пути могут быть относительными при первом запуске — демон запомнит абсолютный путь к файлу.

### Запуск
```bash
sudo ./bin/daemonizer /absolute/path/to/config.conf
```
По умолчанию pid-файл: `/var/run/daemonizer.pid`.

### Сигналы
- SIGHUP — перечитать конфигурацию
- SIGTERM — корректное завершение (пишет в syslog)

Отправка сигнала:
```bash
sudo kill -HUP $(cat /var/run/daemonizer.pid)
sudo kill -TERM $(cat /var/run/daemonizer.pid)
```

### Логи
Запись в системный журнал через `syslog` (`LOG_DAEMON`).

### Проверка работы
1. Подготовьте каталоги `in` и `out`.
2. Создайте конфиг, например:
   ```
   interval=1000
   ./in ./out txt
   ```
3. Запустите демона.
4. Положите файлы `*.txt` в `in` — раз в секунду `out` очищается и наполняется копиями из `in`.
5. Меняйте конфиг и шлите `SIGHUP` для горячей перезагрузки.

### Разработка
- Очистка: `bash build.sh clean`
- Пересборка: `bash build.sh build`
